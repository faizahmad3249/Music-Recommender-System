# Music Recommender System

A Streamlit-based Music Recommendation System using Spotify API.

## Features
- Song recommendations
- Album cover fetching
- Streamlit UI
- Spotify integration

## Run Locally

Install requirements:

pip install -r requirements.txt

Run app:

streamlit run app.py

## Important

The file `similarity.pkl` is not uploaded to GitHub because of GitHub file size limitations.

Place `similarity.pkl` manually in the project folder before running the project.
